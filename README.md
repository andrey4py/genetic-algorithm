# genetic algorithm
Реализация генетического алгоритма для оптимизации многомерных функций. Поддерживает hex и бинарное кодирование, турнирную и ранговую селекцию, одноточечный и двухточечный кроссовер. Предназначен для решения задач непрерывной оптимизации.

## Стек технологий

- **Язык:** Python 3.7+
- **Библиотеки:**
  - `random` – генерация случайных чисел
  - `math` – математические вычисления
  - `numpy` – численные операции и вероятностная селекция
- **Интерфейс:** командная строка 

## Функциональные возможности

### Схемы кодирования
- Hex-кодирование (4 hex-символа на ген, 16⁴ градаций).
- Бинарное кодирование (16 бит на ген, 65536 градаций).

### Методы селекции
- Турнирная селекция (выбор лучшего из случайной подгруппы).
- Ранговая селекция (вероятностный выбор на основе ранга).

### Операторы кроссовера
- Одноточечный кроссовер.
- Двухточечный кроссовер.

### Механизм мутации
- Hex: случайная замена символа на другой hex-символ.
- Bin: инверсия бита (0→1, 1→0).
- Вероятность мутации: 20% на хромосому.

### Тестовые функции
- Sphere.
- Rastrigin.
- Rosenbrock.
- Ackley.

### Дополнительно
- Элитизм (сохранение лучшей особи поколения).
- Нормализация значений в генетический код.
- Фитнес-функция: 1/(1+|f(x)|).
